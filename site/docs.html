Un environnement.
Une mission.
À vous de construire.

Ce guide installe le runtime local expérimental. La page d’accueil est une maquette visuelle rebrandée de PhoneUse ; elle ne représente pas une offre cloud STROWGER déjà disponible.

Ouvrir la console locale.

Prérequis : Python 3.11+, macOS ou Linux. ADB est nécessaire pour les Android, Docker pour le bureau Linux. Cette version fournit les environnements à vos agents, sans appeler de modèle d’IA.

git clone https://github.com/strowgerV1/strowger-env.git
cd strowger-env
# macOS : installer les Android SDK Platform Tools officiels
# Avec Homebrew : brew install --cask android-platform-tools
sh scripts/preparer-pilote.sh
.venv/bin/strowger serve --capacity 6 --port 8876 --open

Sur Mac, double-cliquer ensuite sur Banc-telephones.command et choisir 3. La console s’ouvre avec un code de connexion à usage unique. La clé API reste privée, dans le fichier local .env.

Ouvrir la console sur ce Mac ↗ · Le serveur local doit être démarré.

Réservez un navigateur, cliquez sur « Essayer la page de démonstration locale », remplissez le champ #name, puis cliquez sur button. La capture affiche « Bonjour STROWGER ». Renouvelez la session ou libérez-la depuis la même interface.

Le contrat de lease.

from strowger_env.client import Runtime

with Runtime("http://127.0.0.1:8876", api_key) as runtime:
    with runtime.browser.acquire(ttl=300) as lease:
        lease.act("navigate", url="https://example.com")
        result = lease.act("observe")
        lease.renew(ttl=300)
    # Libération automatique en sortie du bloc.
ActionRoute
AcquérirPOST /v1/leases
Observer l’étatGET /v1/leases/{id}
AgirPOST /v1/leases/{id}/actions
RenouvelerPOST /v1/leases/{id}/renew
LibérerDELETE /v1/leases/{id}

Authentification : une clé API par agent, et un jeton distinct par lease. Le serveur expose son OpenAPI interactif sur /docs une fois démarré. Les écrans MCP de la maquette sont des illustrations : l’adaptateur MCP reste à développer.

Le desktop Linux.

.venv/bin/strowger desktop
# Docker doit être démarré. Puis relancer le broker.
# SDK : runtime.desktop.acquire(ttl=60)

Le conteneur est éphémère, sans réseau et sans dossier hôte monté. Depuis la console, vous pouvez le réserver, cliquer dans la capture, saisir du texte et le libérer.

Votre banc Android.

Connectez jusqu’à six Android de laboratoire, déverrouillez-les et autorisez le débogage USB. L’enregistrement ne pilote pas leur écran.

.venv/bin/strowger doctor
.venv/bin/strowger enroll --owner alice --limit 6
# Redémarrer le broker pour charger l’inventaire.
.venv/bin/strowger serve --capacity 6 --port 8876 --open

Les appareils enregistrés apparaissent dans la console. Réservez-en un pour afficher sa capture, toucher l’écran, balayer, revenir à l’accueil, lancer une application par son package ou saisir du texte ASCII. La libération revient à l’accueil, sans effacer les données. La validation sur les téléphones physiques est prévue le 23 octobre.

Le runtime est mono-processus, avec un registre en mémoire. Chromium utilise le réseau de l’hôte. Les agents doivent être de confiance. Avant un cloud multi-tenant : workers isolés, état persistant, contrôle réseau, quotas et reprise après crash.

Reproduire le site.

# Depuis la racine du dépôt public :
cd site
npm run dev -- --host 127.0.0.1 --port 4173
# Ouvrir http://127.0.0.1:4173
npm run build

La scène 3D est exécutée par Three.js à partir d’un modèle GLB local, avec décompression Draco. Les polices sont locales. Les modules contrôlent la caméra, les animations au scroll, le raycasting des pièces et les micro-interactions.

Données de la maquette.

La page marketing n’est reliée ni au broker local ni à un compte PhoneUse. Le formulaire de démonstration n’envoie et ne conserve aucune donnée. Les boutons de copie utilisent le presse-papiers, le thème est mémorisé dans le navigateur. Les médias sont servis localement au site. Les tarifs, performances et chiffres de flotte sont illustratifs et issus de la référence.
