        01What's the difference between a cloud phone and a real phone?
        
    Cloud phones are virtual Android devices that boot in seconds and scale to hundreds. Real phones are retail iPhones and Androids in our San Francisco rack, tapped by a robot stylus, for apps that detect emulators.
    
      
    
      
    
        02Is the iPhone really unmodified?
        
    Yes. No jailbreak, no root and no helper app. It's a retail iPhone with a real carrier SIM. A stylus touches the glass and an overhead camera reads the screen, so the phone runs exactly as it shipped.
    
      
    
      
    
        03Which agents and clients does it work with?
        
    Any MCP client, including Claude, Cursor, Codex and Windsurf. You can also use the API or the CLI.
    
      
    
      
    
        04Can I switch between cloud and real?
        
    Yes. Every phone uses the same API, the same MCP tools and the same CLI, so you only point your agent at a different phone. Most teams build on cloud phones and move the flows that get blocked onto real ones.
    
      
    
      
    
        05Can my agent receive SMS and 2FA codes?
        
    On real phones, yes. Each one has a real carrier number, so verification codes arrive the way they would for a person, and your agent reads them in Messages.
    
      
    
      
    
        06How does per-minute billing work?
        
    On-demand cloud phones cost $0.024 for each minute a phone is running. You pay for the exact time used, so part of a minute costs part of the rate. Dedicated cloud phones and real phones are a flat monthly price.
